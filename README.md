# Doggie's New Vehicle / 狗狗的新车

Doggie's New Vehicle (DNV) is an unofficial add-on for Superb Warfare. It adds heavy artillery, armored vehicles, strategic launch sites, and large combat units. Its naval content includes the Libertad battleship, Yue-class aircraft carrier, and Feiying carrier fighter. The DNV creative tab contains the English and Simplified Chinese player guides.

狗狗的新车（DNV）是卓越前线的非官方附属模组，包含重型火炮、装甲载具、战略发射设施和大型战斗单位，以及自由号战列舰、岳级航空母舰和飞鹰型舰载机。DNV 创造物品栏内有简体中文和英文两本玩法手册。
