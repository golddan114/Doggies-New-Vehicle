# DNV · Next release

**Minecraft 1.20.1 / Forge · Minecraft 1.21.1 / NeoForge**

## Fixes and improvements

- **Yue-class aircraft carrier.** When it reaches zero durability, it immediately plays an explosion sound and effects. Its wreck still falls and the final explosion occurs on impact.
- **Feiying carrier fighter.** A lethal hit now leaves a visible wreck and plays explosion effects. If the fighter was on deck, its hangar bay can accept a replacement crate.
- **English and Simplified Chinese.** Updated several entity display names and the ship and fighter entries in both in-game player guides.

## Requirements

- **Minecraft 1.20.1 / Forge 47.4.18 or newer in 47.x.** Java 17, Superb Warfare 0.8.9.2 `65d985a64`, and GeckoLib 4.8.4.
- **Minecraft 1.21.1 / NeoForge 21.1.227 or newer in 21.1.x.** Java 21 and Superb Warfare 0.8.9.2 hotfix `e0c2b27f`.

Install the matching DNV, Superb Warfare and its dependencies on the client and server. Remove any separately installed Libertad or Yue naval preview before upgrading.

# DNV · 下版更新日志

**Minecraft 1.20.1 / Forge · Minecraft 1.21.1 / NeoForge**

## 修复与优化

- **岳级航空母舰。** 耐久归零时立即播放爆炸声光。残骸继续下坠，触地时触发最终爆炸。
- **飞鹰型舰载机。** 受到致命伤害后播放爆炸效果并保留坠落残骸。在甲板上被击毁时，对应仓位可装入新的飞鹰集装箱。
- **中英双语。** 补齐若干实体的显示名称，更新两本游戏内玩法手册中的岳级和飞鹰说明。

## 版本要求

- **Minecraft 1.20.1 / Forge 47.4.18 及以上的 47.x 版本。** Java 17、卓越前线 0.8.9.2 `65d985a64`、GeckoLib 4.8.4。
- **Minecraft 1.21.1 / NeoForge 21.1.227 及以上的 21.1.x 版本。** Java 21、卓越前线 0.8.9.2 hotfix `e0c2b27f`。

客户端和服务端均安装对应平台的 DNV、卓越前线及其前置。升级时请移出此前单独安装的自由号或岳级试玩包。
